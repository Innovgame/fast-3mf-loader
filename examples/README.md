# Examples

The local test page is the first example. From the repository root:

```bash
pnpm install
pnpm dev
```

The same page is published at <https://innovgame.github.io/fast-3mf-loader/> after CI succeeds on `master`.

Sample archives live in `3mf/`. Their licenses are recorded in `3mf/README.md`. `multipletextures.3mf` is the large fixture used by the benchmark. It is a regression input, not a guarantee that every 3MF extension is supported.
