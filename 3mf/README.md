### Removed: truck.3mf

`truck.3mf` and the extracted `truck.model` were removed on 2026-10-13. The copy matched [`examples/models/3mf/truck.3mf`](https://github.com/mrdoob/three.js/blob/dev/examples/models/3mf/truck.3mf) in three.js, SHA-256 `242ff6467b34b47c75c5a5b6417db30da15e45b805bbe0a0245bb5cca0a03a86`. The three.js example README does not state a separate license for that file, so this repository no longer distributes it.

Component coverage now uses a small archive generated in the test suite. Large-fixture measurements use the BSD-licensed `multipletextures.3mf`.
